### **[SLIDE 1-2: TITLE & THE PROBLEM - 90 SECONDS]**

"So let me set the context.

Before ArenaHub, here's what the experience looked like:

**You wanted to book a venue, so:**
- You'd call 5-6 venues
- Get different prices from each
- No written confirmation
- Payment was cash on spot—risky
- If something went wrong, no protection
- Players had no way to connect with captains
- Owners had no way to manage bookings

It was chaotic. Venue owners managed everything manually. Players were confused. Captains had to coordinate 10+ people through WhatsApp.

There had to be a better way."

---

### **[SLIDE 3: OUR SOLUTION - 60 SECONDS]**

"So we built ArenaHub.

Think of it as: **Airbnb for sports venues** but way more specialized.

What we do:
- Players come and browse available venues
- Filter by sport, city, price—find the right venue in seconds
- Click to book—instant confirmation
- Pay online—secure, traceable
- Captains can book for entire squads
- Venue owners can manage everything in one dashboard
- Admins oversee disputes and ensure fairness

It's not just a booking system. It's a complete ecosystem for sports."

---

### **[SLIDE 4: THE FOUR USER TYPES - 120 SECONDS]**

"Now here's what makes ArenaHub different from other booking apps.

We realized that **different users need completely different experiences.**

So instead of building one generic app, we built four specialized dashboards.

**First: PLAYERS**
These are individual gamers who just want to book and play.
When they open ArenaHub, they see:
- Venues near them
- Real-time availability
- Actual prices—no surprises
- Reviews from other players
- They book in 60 seconds and they're done

**Second: CAPTAINS**
These are squad leaders managing 10-15 players.
Their experience is completely different:
- Create and manage teams
- Book for entire squad at once
- Communicate with all players in one place
- Track squad statistics
- Handle player requests

**Third: OWNERS**
These are venue operators trying to make money.
They need:
- A way to list their venue
- Booking management—see all requests
- Pricing control—peak vs off-peak rates
- Revenue tracking—know how much they're making
- Player ratings—build credibility

**Fourth: ADMINS**
These are us—managing the platform.
We handle:
- Verify owners aren't frauds
- Resolve disputes when things go wrong
- Manage payments
- See platform analytics
- Keep things fair for everyone

So four completely different user types, four completely different experiences. That's our key insight."

### **[AFTER DEMO: TECH STACK - 60 SECONDS]**

"Okay, so now you've seen what it does. Let me tell you how we built it.

**Frontend:**
- React with Vite for fast development
- Modern CSS for responsive design
- GSAP for smooth animations
- Three.js for 3D visual effects

**Backend:**
- Java Servlets handling all business logic
- Apache Tomcat as the web server
- RESTful APIs connecting frontend to backend

**Database:**
- MySQL with proper schema
- 6+ interconnected tables
- User, Bookings, Venues, Squads, Chat, Disputes, Wallet

**Architecture:**
```
React App (Browser)
        ↓ HTTP/API calls
Java Servlet Backend
        ↓ SQL
MySQL Database
```

Why this stack?
- React: Best frontend framework, huge community
- Java: Enterprise-grade, secure, handles financial transactions well
- MySQL: Proven for marketplaces, great for relational data

This combination is used by companies like Netflix, Instagram—it's production-ready."

### **[BUSINESS MODEL - 90 SECONDS]**

"Now, how do we make money?

We don't charge players or owners to use the platform. Instead, we make money from the transactions.

**Commission Model:**
- Every booking that happens, we take 10-15% commission
- Example: ₹500 booking = ₹50 to ArenaHub

Why is this good?
1. Players still save money compared to phone booking hassle
2. Owners can raise prices by 2% and still come out ahead
3. We only make money if everyone is happy and booking
4. Aligns everyone's incentives

**Secondary Revenue:**
1. Premium owner listings: Featured placement, ₹500-1000 per month
2. Equipment rental commissions
3. Analytics tools for owners
4. Eventually: Advertising

**Financial Projection:**
- 100 active venues
- 1,000 active players
- 500 bookings per day
- ₹500 average booking
- 12% commission

Daily: 500 × ₹60 = ₹30,000
Monthly: ₹900,000
Yearly: ₹1.08 crores

And this scales. As we grow, revenue grows proportionally."
